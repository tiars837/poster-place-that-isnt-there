## The place

Velmara is a chain of floating isles drifting above a sea of clouds. On the
largest isle stands the Skyneedle, a crystal spire whose beacon burns gold
at dusk, while waterfalls spill off the grassy cliffs and dissolve into
mist below. The sky never touches the sea here — the sea is cloud, and the
sun sets twice: once in the sky, once in the gold beneath your feet.

## How to run

```sh
python3 main.py
```

Writes a 1024x1024 PNG to `/output/entry.png` (or `$POSTER_OUTPUT`).
Pure Python 3 standard library, no network, no external files.

The program is deterministic: running it twice produces byte-identical
output.
